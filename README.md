# Raconteur

> Literature you want to read.

A quiet literary home on the internet — a publishing platform for short fiction
and poetry where stories get room to breathe. No algorithms, no noise, no slush
pile. Writers publish instantly; readers settle into a distraction-free
experience with drop caps, pull quotes, three reading modes and adjustable type.

## Stack
- Astro (SSR) + TypeScript
- Supabase (Postgres, Auth, Storage, Row Level Security)
- Node standalone adapter

## Local development
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your Supabase keys
3. `npm run dev`

## Soul
Every story here was written to be remembered.
